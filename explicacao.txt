COMPILADORES (AV3)

1. O QUE JA ESTA PRONTO
- Leitura do arquivo de entrada via terminal
  (ex: python lexico.py teste.c).
- Reconhecimento dos tokens basicos: tipos
  (int, float, etc.), identificadores, numeros,
  operadores e delimitadores.
- Ignora espacos em branco e comentarios de linha (//).
- Criacao e exibicao da lista sequencial de tokens com
  linha, tipo e lexema.
- Criacao e exibicao da tabela de simbolos basica com
  ordem de insercao, nome do simbolo e categoria.

2. COMO O CODIGO FUNCIONA HOJE
- O script usa a biblioteca 're' com expressoes
  regulares para casar cada trecho de texto com uma
  regra predefinida.
- As regras tem prioridade ordenada: tipos vem antes de
  identificadores para evitar que palavras como 'int'
  virem variaveis.
- O arquivo e percorrido linha por linha guardando o
  numero exato da linha de cada token.
- Sempre que um tipo ou identificador aparece pela
  primeira vez, ele entra na tabela de simbolos sem
  repeticoes.

3. O QUE AINDA FALTA FAZER
- Analise Sintatica (Parser): criar a logica para
  verificar se os tokens estao na ordem gramatical
  correta (ex: validar a estrutura de atribuicao:
  identificador = expressao;).
- Arvore Sintatica (AST): estruturar e imprimir a arvore
  do comando no terminal.
- Analise Semantica: implementar ao menos uma regra
  basica de validacao, como barrar variavel sem
  declaracao previa ou checar tipos incompativeis.

4. DUVIDAS DA EQUIPE E PONTOS DE MELHORIA
- Variavel sem declarar: no arquivo teste.c atual, a
  linha 'x = a + 5;' usa a variavel 'a', mas 'a' nao foi
  declarada antes. Precisamos decidir se deixamos isso
  de proposito para disparar o erro semantico ou se
  declaramos 'a' no inicio.
- Tipo de dado na tabela: hoje os identificadores
  entram com tipo 'indefinido' porque o lexico nao sabe
  o contexto da declaracao. Precisamos amarrar o tipo
  certo na etapa sintatica/semantica.
- Caracteres invalidos: o lexico atual apenas pula
  caracteres estranhos (como @ ou $); podemos melhorar
  para acusar erro lexico imediatamente com a linha onde
  ocorreu.
- Escolha da analise sintatica: decidir como construir o
  parser de forma simples em Python (usando recursao
  manual ou uma pilha simples).
